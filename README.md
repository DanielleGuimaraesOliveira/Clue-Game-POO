# Clue-Game-POO
Repositório reservado para o desenvolvimento em Java do jogo CLUE (Detetive) para a disciplina de Programação Orientada à Objeto

## Configurar setup inicial

```bash
make setup
```

## Comandos do Makefile

| Comando | Descrição |
|---------|-----------|
| `make setup` | Instala Git Hooks para validação pré-push |
| `make compile` | Compila os arquivos fonte e copia assets |
| `make compile_test` | Compila arquivos fonte e testes |
| `make test` | Executa todos os testes (JUnit) |
| `make check_format` | Análise de formatação com Checkstyle |
